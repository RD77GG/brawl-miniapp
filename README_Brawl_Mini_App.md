# Brawl Mini App

Мини-приложение и каталог по Brawl Stars, размещённый на GitHub Pages.

## Цель проекта

Создать удобную русскоязычную энциклопедию бойцов и скинов Brawl Stars с интерфейсом, похожим на игру.

## Текущая структура

```text
BrawlStarsMiniApp/
├── index.html
├── brawler.html
├── css/
│   ├── common.css

├── js/
```

## Уже реализовано

- Главная страница с карточками бойцов.
- Поиск бойцов по русскому имени.
- Переход на страницу выбранного бойца.
- Кнопка возврата на главную страницу.
- Изображение, имя, редкость и класс бойца.
- Цветные обозначения редкости и класса.
- Вкладки «Скины» и «Информация».
- Карточки скинов.
- Титулы бойца.
- Подготовленная структура папок для валют и коллекций.

## Страница бойца

Верхняя часть страницы остаётся одинаковой во всех вкладках:

- изображение бойца;
- имя;
- редкость;
- класс;
- переключатель «Скины / Информация».

### Вкладка «Скины»

Каждая карточка должна показывать:

- изображение;
- русское название;
- коллекцию и её иконку;
- редкость цветным текстом без яркой плашки;
- цену с изображениями гемов и блингов;
- либо источник получения, например иконку и текст `Brawl Pass`;
- год выхода справа снизу.

### Полноэкранный просмотр скина

При нажатии карточка должна открываться поверх страницы и показывать:

- большое изображение;
- название;
- коллекцию;
- редкость;
- стоимость или источник получения;
- полную дату выхода;
- описание;
- кнопку закрытия;
- в будущем — переключение между скинами свайпом.

### Вкладка «Информация»

Планируемые разделы:

- титулы;
- описание бойца;
- звёздные силы;
- гаджеты;
- гиперзаряд;
- другие способности.

## Правила файлов

- Папки и новые файлы называть маленькими латинскими буквами.
- Для каждого бойца использовать отдельную папку внутри `images/brawlers/`.
- Пути и регистр расширений должны совпадать с GitHub символ в символ.
- Даты хранить в формате `YYYY-MM-DD`.
- Русские названия выводить через `displayName`.
- Английское служебное имя хранить в `name`.

3. Обновить `css/brawler.css` под новый дизайн карточек.

5. Добавить свайпы между скинами.
6. Заполнить способности Шелли.
7. Добавлять следующих бойцов и их скины.
